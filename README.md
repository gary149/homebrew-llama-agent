# Gary149 Llama-agent

## How do I install these formulae?

`brew install gary149/llama-agent/<formula>`

Or `brew tap gary149/llama-agent` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "gary149/llama-agent"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
